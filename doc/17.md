## JPA 中用 @Query 自定义 JPQL 查询的方法声明。
```java
// from Theme t  -- 从 Theme 实体查询，并给别名 t
// 这里的 Theme 代表 Theme模型不是表名
@Query("select t from Theme t where t.name in (:names)")
List<Theme> findByNames(List<String> names);

等价 SQL 大致是:
SELECT t.* FROM theme t WHERE t.name IN (?, ?, ...);
```
